# 로또

간단한 로또 발매기를 구현하는 프로젝트입니다.
사용자로부터 구매 금액을 입력받아 로또를 발행하고, 당첨 번호와 비교하여 당첨 내역 및 수익률을 계산합니다.

## 기능 목록

### 1. 로또 번호, 로또 생성 및 검증 기능
- [x] 로또 번호 6개를 입력받아 Lotto 객체를 생성한다.
  - [x] 로또 번호가 6개인지 검증한다.
  - [x] 로또 번호가 1~45 범위 내에 있는지 검증한다.
  - [x] 로또 번호에 중복이 없는지 검증한다.
  - [x] 생성된 로또 번호를 오름차순으로 정렬한다.
- [x] 1~45 사이의 중복되지 않는 숫자 6개를 자동으로 생성한다 -> 로또 숫자 랜덤 생성.

### 2. 구입 금액 입력 기능
- [x] 구입 금액을 입력받는다.
  - [x] 구입 금액이 숫자인지 검증한다.
  - [x] 구입 금액이 1,000원 단위인지 검증한다.
  - [x] 구입 금액이 양수인지 검증한다.
- [x] 구입 금액으로 구매 가능한 로또 개수를 계산한다.

### 3. 로또 발행 및 출력 기능
- [x] 구매한 개수만큼 로또를 생성한다.
- [x] 구매한 로또 개수를 출력한다.
- [x] 생성된 로또 번호들을 출력한다.

### 4. 당첨 번호 입력 기능
- [x] 당첨 번호 문자열을 입력받는다.
  - [x] 쉼표로 구분된 당첨 번호를 파싱한다.
    - Lotto 클래스의 검증 로직을 활용한다.

### 5. 보너스 번호 입력 기능
- [ ] 보너스 번호를 입력받는다.
- [ ] 보너스 번호가 숫자인지 검증한다.
- [ ] 보너스 번호가 1~45 범위 내에 있는지 검증한다.
- [ ] 보너스 번호가 당첨 번호와 중복되지 않는지 검증한다.

### 6. 당첨 확인 기능
- [ ] 로또 번호와 당첨 번호의 일치 개수를 계산한다.
- [ ] 로또 번호에 보너스 번호가 포함되어 있는지 확인한다.
- [ ] 일치 개수와 보너스 번호 일치 여부로 당첨 등수를 판별한다.
    - [ ] 6개 일치 시 1등으로 판별
    - [ ] 5개 일치 + 보너스 일치 시 2등으로 판별
    - [ ] 5개 일치 시 3등으로 판별
    - [ ] 4개 일치 시 4등으로 판별
    - [ ] 3개 일치 시 5등으로 판별
- [ ] 모든 로또에 대해 당첨 결과를 확인한다.

### 7. 당첨 통계 기능
- [ ] 각 등수별 당첨 개수를 집계한다.
- [ ] 각 등수별 당첨 금액을 정의한다.
    - [ ] 1등: 2,000,000,000원
    - [ ] 2등: 30,000,000원
    - [ ] 3등: 1,500,000원
    - [ ] 4등: 50,000원
    - [ ] 5등: 5,000원
- [ ] 총 당첨 금액을 계산한다.

### 8. 수익률 계산 기능
- [ ] 총 당첨 금액을 구입 금액으로 나누어 수익률을 계산한다.
- [ ] 수익률을 백분율로 변환한다.
- [ ] 수익률을 소수점 둘째 자리에서 반올림한다.

### 9. 당첨 통계 출력 기능
- [ ] 당첨 통계 헤더를 출력한다.
- [ ] 각 등수별 당첨 내역을 출력한다.
    - [ ] 3개 일치 당첨 내역 출력
    - [ ] 4개 일치 당첨 내역 출력
    - [ ] 5개 일치 당첨 내역 출력
    - [ ] 5개 일치 + 보너스 당첨 내역 출력
    - [ ] 6개 일치 당첨 내역 출력
- [ ] 총 수익률을 출력한다.

### 10. 예외 처리 기능
- [ ] 예외 발생 시 "[ERROR]"로 시작하는 메시지를 출력한다.
- [ ] 예외 발생 시 해당 입력부터 다시 받는다.

## 실행 예시

```
구입금액을 입력해 주세요.
8000

8개를 구매했습니다.
[8, 21, 23, 41, 42, 43] 
[3, 5, 11, 16, 32, 38] 
[7, 11, 16, 35, 36, 44] 
[1, 8, 11, 31, 41, 42] 
[13, 14, 16, 38, 42, 45] 
[7, 11, 30, 40, 42, 43] 
[2, 13, 22, 32, 38, 45] 
[1, 3, 5, 14, 22, 45]

당첨 번호를 입력해 주세요.
1,2,3,4,5,6

보너스 번호를 입력해 주세요.
7

당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.
```
